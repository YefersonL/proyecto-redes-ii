# Proyecto Redes II - Monitoreo y Automatización de Topología (RIP / EIGRP / OSPF)

Repositorio de respaldo automatizado de artefactos del laboratorio:
- **`1_topologia_pnetlab/`**: Archivo nativo `Proyecto.unl` de PNETLab.
- **`2_configs_red/`**: Configuraciones (`running-config` / `startup-config`) de los routers y switches.
- **`3_zabbix/`**: Exportación de hosts, plantillas y esquema de configuración de Zabbix 7.0.
- **`4_grafana/`**: Dashboards en formato JSON y base de datos de visualización.
- **`5_n8n/`**: Flujos de automatización e integración con Bot de Telegram.
- **`6_documentacion/`**: Documentación técnica y evidencias.
